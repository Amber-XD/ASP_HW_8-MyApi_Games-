
# MyApi — Game API

## Опис проєкту

REST API для управління списком ігор.

API підтримує отримання, оновлення, завершення та видалення ігор.

## Реалізовані методи

| HTTP-метод | Адреса | Коди відповіді | Умови |
|---|---|---|---|
| GET | `/api/Game` | 200 | Список ігор успішно отримано. |
| GET | `/api/Game` | 404 | Список ігор порожній. |
| PUT | `/api/Game/{id}` | 200 | Гру успішно оновлено. |
| PUT | `/api/Game/{id}` | 404 | Гру з таким ID не знайдено. |
| PUT | `/api/Game/{id}` | 409 | Назва вже використовується іншою грою. |
| POST | `/api/Game/{id}/complete` | 204 | Гру позначено пройденою. |
| POST | `/api/Game/{id}/complete` | 404 | Гру не знайдено. |
| POST | `/api/Game/{id}/complete` | 409 | Гра вже пройдена. |
| DELETE | `/api/Game/{id}` | 204 | Гру успішно видалено. |
| DELETE | `/api/Game/{id}` | 404 | Гру не знайдено. |
| DELETE | `/api/Game/{id}` | 409 | Гра має пріоритет 5 і ще не пройдена. |
| DELETE | `/api/Game/completed` | 200 | Усі пройдені ігри видалено. Повертається кількість видалених ігор. |

## Перевірка в Swagger

Усі методи перевірено через Swagger UI.

Скріншоти перевірок знаходяться в папці `Screenshots`.

### GET
- 200 — успішне отримання списку ігор.
- 404 — список порожній.

### PUT
- 200 — успішне оновлення гри.
- 404 — гра не знайдена.
- 409 — назва вже використовується іншою грою.

### POST
- 204 — гра успішно позначена пройденою.
- 404 — гра не знайдена.
- 409 — гра вже пройдена.

### DELETE
- 204 — гру успішно видалено.
- 404 — гра не знайдена.
- 409 — заборонено видаляти непройдену гру з пріоритетом 5.
- 200 — видалено всі пройдені ігри, повернуто кількість видалених.
